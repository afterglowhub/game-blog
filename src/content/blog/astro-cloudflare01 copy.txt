「ブログの維持費、毎月払うのしんどくない？」

そう思って、**完全無料で爆速のブログ環境**を作ってみました。結論から言うと、**マジで快適すぎてWordPressには戻れません。**

# 結論：作ってみて分かった「これヤバい」ポイント3つ

## 1. 維持費が年間ドメイン代だけ（約1,000円）

**以前（WordPress）：**
- レンタルサーバー：月800円
- 年間9,600円の出費

**今（Astro + Cloudflare）：**
- サーバー代：0円
- ドメイン代：年1,000円のみ
- **年間8,600円の節約**

## 2. 表示速度が別次元

WordPressで「読み込み中...」って待たされるストレス、完全に消えました。

| 環境 | 表示速度 | 体感 |
|---|---|---|
| WordPress | 1.5〜3秒 | 「あれ、重いな...」 |
| Astro | 0.1〜0.3秒 | **「え、もう出た！？」** |

## 3. セキュリティの心配がゼロ

WordPressの「更新してください」通知、もう見なくていいんです。管理画面がないから、ハッキングの心配もほぼゼロ。

# 実際の構築手順：本当に60分でできた

## 準備編：まずアカウント作成（10分）

**必要なのは3つだけ：**
1. **GitHub**（無料）：コードを保存する場所
2. **Cloudflare Pages**（無料）：サイトを世界に公開
3. **VS Code**（無料）：記事を書くエディタ

**Node.jsのインストール：**
```bash
# Ubuntuの場合
sudo apt update
sudo apt install nodejs npm

# バージョン確認（v18以上ならOK）
node --version
```
実践編①：Astroサイト作成（15分）

「黒い画面」が怖い人へ： 大丈夫です。以下をコピペするだけで魔法のように完成します。

```bash
# 作業フォルダ作成
cd ~/Documents/Work
mkdir my-blog
cd my-blog

# この1行で骨格が完成（マジで簡単）
npm create astro@latest . --template blog --no-git --yes

# 必要なファイルをダウンロード
npm install

# ローカルで確認
npm run dev
```
ブラウザで http://localhost:4321 を開くと...

「うわ、もう動いてる！」

サンプル記事付きの美しいブログが表示されます。ここまで本当に15分でした。
実践編②：GitHubに保存（15分）

ここが最初のつまずきポイントでした。

ステップ1：GitHubでリポジトリ作成
```bash
    GitHubにログイン
    右上の「+」→「New repository」
    名前：my-blog（何でもOK）
    Public を選択
    「Initialize this repository」は全てチェック外す（重要！）
```
ステップ2：ローカルとGitHubを接続

```bash
git init
git config --global user.name "あなたの名前"
git config --global user.email "your-email@example.com"

git add .
git commit -m "初回コミット"
git branch -M main

# ここのURLは自分のものに変更
git remote add origin https://github.com/あなたのユーザー名/my-blog.git
git push -u origin main
```
ここで認証エラーが出ました（想定内）

解決法A：VS Code使ってる人（超簡単）

    VS Code左下の「人型アイコン」クリック
    「Sign in with GitHub」
    ブラウザで認証完了
    git push再実行 → 成功！

解決法B：ターミナルのみ（確実）

    GitHub Settings → Developer settings → Personal access tokens
    「Generate new token (classic)」
    repoにチェック、90日有効期限
    生成されたトークン（ghp_で始まる）をコピー
    git push実行時、Passwordにトークンを貼り付け

実践編③：Cloudflare Pagesで世界に公開（20分）

ここが一番ワクワクするポイントです。

ステップ1：Cloudflare Pagesでプロジェクト作成

    Cloudflare Pagesにログイン
    「Create a project」
    「Connect to Git」→「GitHub」
    さっき作ったmy-blogを選択

ステップ2：ビルド設定（ここ重要）
項目 	設定値
Framework preset 	Astro（自動検出）
Build command 	npm run build
Build output directory 	dist

環境変数を追加（これ忘れるとエラーになる）：

    Variable name: NODE_VERSION
    Value: 20

ステップ3：デプロイ実行

「Save and Deploy」をクリック。

1〜3分待つと...

「デプロイ成功！あなたのサイトが公開されました」

提供されたURL（your-blog.pages.dev）をクリックすると、自分のブログが世界中からアクセスできる状態に！

この瞬間、マジで感動しました。
つまずいたポイントと解決法（実体験）
問題1：npm createで「エラー」

原因： フォルダ名に日本語が入ってた

解決法：

# ダメな例
cd ~/ドキュメント/作業/

# 正しい例
cd ~/Documents/Work/

問題2：記事が表示されない

原因： Frontmatter（記事の設定部分）で引用符がぶつかってた

間違い：
title: "記事の"テスト"です"  # 引用符が衝突

正解
title: '記事のテストです'  # 外側をシングルクォートに

問題3：画像パスでエラー

原因： 存在しない画像を指定してた

解決法：
# 画像なしでも全然OK（むしろシンプル）
---
title: '記事タイトル'
description: '説明'
pubDate: '2026-01-30'
# heroImage行は削除
---

独自ドメインで「自分だけのURL」にする

Cloudflareのyour-blog.pages.devでも十分カッコいいですが、独自ドメインにするとさらにプロっぽくなります。

手順：

    お名前.com等でドメイン取得（年1,000円〜）
    Cloudflare Pages → Custom domains
    取得したドメインを入力
    自動でDNS設定完了

数分〜数時間で、自分のドメインでアクセスできるようになります。
記事を書く日常：これが最高に楽

新記事作成の流れ：
# 1. 新しい記事ファイル作成
code src/content/blog/new-post.md


2. 記事を書く（Markdown形式）：
---
title: '新しい記事のタイトル'
description: '記事の説明'
pubDate: '2026-01-31'
---

# 見出し

本文をここに書きます。

## 小見出し

- リスト1
- リスト2

**太字も簡単**
3. 公開（3コマンド）：
```bash
git add .
git commit -m "新記事追加"
git push origin main
git pushした瞬間、Cloudflareが自動でビルド・公開。1〜3分で世界中に反映されます。
```
この快感、一度味わったらやめられません。
WordPressと比較してみた

正直な感想：
項目 	WordPress 	Astro
初期構築 	簡単（管理画面で完結） 	やや複雑（Git必須）
記事執筆 	ビジュアルエディタで直感的 	Markdownで書く（慣れれば快適）
維持費 	年間6,000円〜36,000円 	年間1,000円のみ
表示速度 	普通〜やや遅い 	爆速
セキュリティ 	定期更新必須、リスクあり 	ほぼ心配不要
カスタマイズ 	プラグインで簡単 	コードを書く必要あり

結論：

    すぐ始めたい、技術は避けたい → WordPress
    維持費削減、速度重視、技術学習したい → Astro

私は後者だったので、Astroを選んで大正解でした。
