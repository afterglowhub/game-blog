# はじめに：100点を目指さず、まずは「器」を作る

「ホームページを作ってみたい」と思っても、多くの人が「何から手をつけていいか分からない」と立ち止まってしまいます。

実は、今のレンタルサーバーを使えば、「住所（ドメイン）を決め、土地（サーバー）を借りて、家（WordPress）を建てる」という作業は、ボタン一つで同時に終わらせることができます。

この記事では、専門用語を抜きにして、今日中に名刺にURLを載せられる「器」を公開するまでの最短ルートをまとめます。

# ステップ1：サーバーとドメインをセットで用意する

サイトを動かすための「場所」を確保します。初心者の場合は、設定が最も簡単な「レンタルサーバー（国内大手）」の利用が鉄則です。

ここでは、コストや特徴が異なる3つの主要サーバーを比較しました。

## 結論：用途別おすすめ

**とにかく安く、多数のサイトを運営したい方**

コアサーバー CORE-MINIが最適です。圧倒的コスパで、練習用に最適です。

**知名度と安心感、容量を重視する方**

ロリポップ！ ライトがおすすめです。利用者が多く情報が豊富で安心して使えます。

**表示速度・運用の楽さを重視する方**

ラッコサーバーを選びましょう。LiteSpeed採用で、自動インストールが充実しています。

補足：最新のキャンペーン情報は各公式サイトで最終確認を行ってください。

# ステップ2：「かんたんセットアップ」での入力項目

契約画面で入力を求められるのは、主に以下の5つだけです。

1. ドメイン名：`https://〇〇.com` の「〇〇」の部分
2. サイト名：自分のサイトのタイトル（後から変更可能）
3. ユーザー名：管理画面にログインするための名前
4. パスワード：ログイン用のパスワード（必ずメモしてください）
5. テーマ：無料テーマの王道「Cocoon」を選択します

---

# ステップ3：ブラウザで「自分のURL」を確認する

申し込み完了後、数分〜数十分待つとドメインが反映されます。ブラウザの検索窓に、自分で決めたドメインを直接入力してアクセスしてみてください。

確認用URL：`http://(あなたが決めたドメイン)`

画面に「Hello world!」と表示されれば、拠点の設営は成功です！

## 初心者がつまづきやすい「壁」と対処法

| 失敗例 | 原因 | 解決法 |
|:---|:---|:---|
| 無効なURLです | 反映待ち | 30分ほど置いて再アクセス |
| 保護されていない通信 | SSL設定中 | 自動解決するので1時間ほど待つ |
| ログイン画面不明 | 入口不明 | URL末尾に `/wp-admin` を付けて検索 |

# ステップ4：管理画面にログインして「Cocoon」を整える

## 1. 管理画面へのログイン

ブラウザで `あなたのドメイン/wp-admin` を入力し、ステップ2の情報を使いログインします。ここから先はブラウザだけで完結します。

## 2. Cocoonの設定を確認する

「かんたんセットアップ」でCocoonを選んだ場合、すでにインストールは完了しています。

1. 「外観」→「テーマ」をクリック
2. 一覧から「Cocoon Child（子テーマ）」を選んで「有効化」します

なぜ「子テーマ」を選ぶのか？親テーマはアップデートで中身が書き換わる「本体」です。自分のこだわり（設定）を消さないために、「別冊ノート（子テーマ）」を有効にするのがWordPressの鉄則です。

## 3. テーマが入っていなかったら（手動）

万が一、テーマが見当たらなかった場合は以下の手順で進めます。

- 入手：[Cocoon公式サイト](https://wp-cocoon.com/downloads/)から「親」と「子」のZIPファイルをダウンロード
- 配置：「外観」→「テーマ」→「新しいテーマを追加」からZIPのままアップロード（親を先に、子を後に）
- 有効化：「Cocoon Child」を有効化して完了
